YouTube Trending Video Analytics

Project Overview

This project analyzes YouTube trending videos across 10 countries to identify viewing patterns, category performance, title and tag sentiment, and regional differences.

Objectives

- Clean and standardize datasets from multiple countries.
- Analyze sentiment in video titles and tags.
- Rank video categories by average views using SQL.
- Analyze trending records and trending duration over time.
- Compare video performance across countries.
- Build an interactive Tableau dashboard.

Tools and Technologies

- Python
- Pandas and Matplotlib
- SQLite
- Tableau
- Jupyter Notebook

Dataset

The dataset contains YouTube trending video records from 10 countries.

Source: "YouTube Trending Video Dataset — Kaggle" (https://www.kaggle.com/datasets/datasnaek/youtube-new)

Project Workflow

1. Data collection and integration
2. Data cleaning and standardization
3. Exploratory data analysis
4. Title and tag sentiment analysis
5. SQL-based category ranking
6. Time-series and country-wise visualizations
7. Tableau dashboard development
8. Interpretation and reporting

Key Deliverables

- Cleaned and standardized datasets
- Sentiment analysis results
- SQL category ranking
- Time-series visualizations
- Country-wise comparison charts
- Tableau dashboard
- Final analytical report

Limitations

Sentiment analysis uses a word-based heuristic and may not correctly interpret sarcasm, context, or all languages. Trending duration represents the records observed in the available dataset, not necessarily the complete lifetime of a video's popularity.

Conclusion

This project demonstrates a data analytics workflow combining Python, SQL, visualization, and Tableau to explore YouTube trending video patterns across countries.
